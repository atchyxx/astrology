# astrology

日本占星天歴の形式でホロスコープ表を作成する Web ページ（index.html）です。

生年月日・出生時刻・出生地を入力すると、日本占星天歴の形式で次の表を作成します。

- 星が教えてくれるよいところ（人柄・心・第一印象・考え方・愛情・がんばり方・幸運・向いている仕事・強み・才能の組み合わせ）
- 今週の星読み・来月の運勢（ラッキーデー・気を付けたい日・毎日のポイント・人に伝える文章のコピー）
- 出生地は都道府県庁所在地から選ぶほか、地名・住所で検索（国土地理院・OpenStreetMap）や緯度・経度の直接入力も可能
- 円形ホロスコープ（出生図・今日の星・出生図＋今日の二重円）
- 天体位置（太陽〜冥王星・ドラゴンヘッド・ASC・MC のサイン、度数、黄経、日運動、逆行、ハウス）
- ハウスカスプ（プラシーダス／イコール／ホールサイン）
- アスペクト表（合・60°・90°・120°・180°、オーブ付き）
- エレメント・クオリティの集計

天体位置は [Astronomy Engine](https://github.com/cosinekitty/astronomy) による計算値です（インターネット接続が必要）。
